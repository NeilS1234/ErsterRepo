## Was noch erforderlich ist

Der Lernplan verlangt einen Milestone, mindestens fünf Issues, passende Labels, ein Project Board und ein erledigtes Issue mit Verknüpfung zu einem Pull Request. Die Beschreibung dieses Ablaufs weist seine Durchführung noch nicht nach.

| Anforderung | Geprüfter Stand |
|---|---|
| Ein Milestone | GitHub liefert aktuell keinen Milestone |
| Mindestens fünf Issues | GitHub liefert keine regulären offenen oder geschlossenen Issues |
| Passende Labels | Anwendung auf Aufgaben-Issues ist mangels solcher Issues nicht nachgewiesen |
| Project Board | Wegen fehlender Zugriffsrechte ungeprüft; bitte einen einsehbaren Link angeben |
| Erledigtes Issue mit PR-Verknüpfung | Nicht nachgewiesen; keine regulären Issues und keine neuen PRs |
| Dokumentation tatsächlicher Schritte und Ergebnisse | README beschreibt geplante Schritte ohne Issue-Nummern, Milestone-/Board-Links, Befehle oder beobachtete Ergebnisse |

Zähle vorhandene PR-Nummern nicht als die fünf geforderten Aufgaben-Issues: GitHub liefert PRs zwar über die Issues-API, für diese Übung sind es jedoch unterschiedliche Arbeitsergebnisse.
