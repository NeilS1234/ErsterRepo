## Python Apprenticeship
Dieses Repository dokumentiert meinen Einstieg in die Programmiersprache Python und begleitet meine Lernfortschritte im Rahmen des Python Apprenticeship.
Das Projekt besteht aus mehreren Lerntagen. An jedem Tag werden neue Python- und Git-Grundlagen erarbeitet und anschließend in einer praktischen Aufgabe umgesetzt.

## Lernziele 
Im Verlauf des Projekts lerne und übe ich unter anderem:
* Grundlagen der Programmiersprache Python
* Erstellen und Ausführen von Python-Programmen
* Arbeiten mit dem Terminal
* Versionsverwaltung mit Git
* Arbeiten mit GitHub-Repositories
* Variablen und verschiedene Datentypen
* Python-Datenstrukturen
* Formatierung von Text mit f-Strings
* Dokumentation eines Projekts mit einer README-Datei
