## Python Apprenticeship
Dieses Repository dokumentiert meinen Einstieg in die Programmiersprache Python und begleitet meine Lernfortschritte im Rahmen des Python Apprenticeship.
Das Projekt besteht aus mehreren Lerntagen. An jedem Tag werden neue Python- und Git-Grundlagen erarbeitet und anschließend in einer praktischen Aufgabe umgesetzt.

## Lernziele 
Im Verlauf des Projekts lerne und übe ich unter anderem:
* Grundlagen der Programmiersprache Python
* Erstellen und Ausführen von Python-Programmen
* Arbeiten mit dem Terminal
* Versionsverwaltung mit Git
* Arbeiten mit GitHub-Repositories
* Variablen und verschiedene Datentypen
* Python-Datenstrukturen
* Formatierung von Text mit f-Strings
* Dokumentation eines Projekts mit einer README-Datei

## Getting Started
Für die Bearbeitung des Projekts werden folgende Programme benötigt:
* Python 3
* Git
* Ein Code-Editor, z. B. Visual Studio Code
* Ein GitHub-Account 

## Day 1 — Python and Git Setup#
* Python zu installieren und Programme auszuführen
* mit dem Terminal zu arbeiten
* Git und GitHub zu verwenden
* Repositories, Commits und Pushes zu verstehen

## Aufgabe
* GitHub Repository python-apprenticeship erstellen
* README erstellen
* Erstes Python-Programm schreiben
* Willkommensnachricht und persönliche Informationen ausgeben
* Projekt committen und auf GitHub pushen

## Day 2 — Variables and Data Types
* Variablen
* Strings, Integers, Floats und Booleans
* Listen, Tupel, Dictionaries und Sets
* f-Strings
* grundlegende Git-Befehle wie status, add, commit und log

## Aufgabe
Ein Python-Programm erstellen, das Informationen über fünf Mitarbeiter oder Produkte speichert und ausgibt.
Dabei sollen mindestens drei verschiedene Datenstrukturen verwendet werden.
